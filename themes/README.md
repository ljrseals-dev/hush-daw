# HUSH GUI themes

| File | Use |
|------|-----|
| `hush-cyan.json` | Default studio (cyan accent) |
| `hush-slate.json` | Forensic / security console density |
| `hush-midnight.json` | Immersive / object-based session mood |
| `hush-cosmic.json` | Cosmic Studio public-fork aesthetic (violet / nebula) |

All themes ship in-tree. No network fetch. Colors are sRGB hex.
